# SQER Rush v1.1 — fixed рабочая версия

## Запуск

Распакуй архив и открой `index.html`.
Если браузер капризничает, запусти из папки игры:

```bash
python3 -m http.server 8000
```

Потом открой `http://localhost:8000`.

## Важно

Если клавиши не реагируют — один раз кликни по окну игры. В v1.1 canvas получает фокус сам, но браузеры иногда любят изображать администратора Любу.

## Управление

- `WASD` / стрелки — движение
- `E` — взять/отдать
- `1–5` — взять конкретную позицию с раздачи/барной станции
- `Q` — переделать последнюю позицию
- `R` — раннер во второй смене
- `P` — пауза
- `M` — звук
- `H` — помощь
- `Enter` / `Space` / клик — продолжить
- `1 / 2` в меню — выбрать смену

## Что исправлено в v1.1

- Починена реакция на клавиши: добавлен фокус canvas, нормализация клавиш и поддержка русской раскладки.
- Добавлен `Space` как дополнительная кнопка подтверждения.
- Интерфейс перерисован компактнее: заказы, поднос и раздача больше не лезут друг на друга.
- Экран выбора уровней стал чище.
- Экран персонажей стал аккуратнее.
- Подсказки вынесены вниз, чтобы не перекрывать игру.

## Исправления v1.2

- Исправлено направление официанта и бармена влево/вправо: спрайты больше не смотрят в противоположную сторону.
- Добавлены визуальные бейджи над столами/гостями: номер и количество оставшихся блюд.
